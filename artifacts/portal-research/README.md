# Portal research output

This directory is populated by the `Research all RFP portals` GitHub Actions workflow.

The completed run writes:

- `portal-research-audit.json`: per-portal queries, inspected official pages, accepted evidence, rejected candidates, errors, and terminal research status.
- `portal-research-summary.json`: catalog coverage and aggregate counts.

A portal is not marked verified merely because its procurement homepage exists. Verified records require an official procurement artifact containing both an Occu-Med service signal and a procurement signal.
